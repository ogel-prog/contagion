Situation Report

ストーリー

未知の病原体が世界各地で同時に確認された。幸い、病原体そのものは治療可能だった。しかし問題は、その感染速度だった。

感染した都市では病原体が変異し、時間が経つほど治療が困難になる。さらに、ひとつの病原体を完全に制圧したと思っても、再び感染が発生する可能性がある。

あなたは医療班として、4種類の病原体が広がる都市へ派遣された。手元にあるのは、限られた研究資源と、現場で使える医療機器だけ。研究によって病原体を弱体化させることはできる。しかし、研究資源は無限ではない。そして、感染は待ってくれない。

すべての病原体を制圧できるか。それとも、都市が感染に飲み込まれるのが先か。

Setup — 全6ステップ

セットアップ

スートごとに分ける

52枚のトランプを ♠13枚・♦13枚・♥13枚・♣13枚 の4つの山に分けます。ジョーカーがある場合は除外します。それぞれの山をシャッフルします。

各エリアに4枚ずつ配置する

各スートの山札から4枚を引き、そのスートの2×2エリアに表向きで配置します。ここに配置されたカードが感染カードとなります。

初期アウトブレイクの確認

各エリアの4枚のランクを合計します (A = 1、J / Q / K = 10)。合計が 28を超える エリアがある場合、そのエリアは再シャッフルして4枚を配置し直します。ゲーム開始時点でアウトブレイク状態にならないようにするためです。

残りのカードを山札にする

4エリアに配置されなかった36枚をまとめてシャッフルし、山札にします。ゲーム中、感染カード・研究カードはこの山札から引きます。捨てられたカードは捨て札になります。

研究カードを引く

医療班はゲーム開始前に、山札から3枚を引きます。これが研究カードとなり、プレイヤーの手元に表向きで置いておきます。

医療班の初期位置を決める

ダイスを3個振り、合計値を求めます。16マスに以下の順で番号を振り、ダイスの合計値のマスに医療班を配置します。17なら1、18なら2に戻ります。

PHASE A

感染フェーズ

山札からカードを1枚引きます。引いたカードのスートと同じエリアが感染します。

未治療のカードがある場合 ― 引いたカードと同じスートエリアを確認し、引いたカードよりランクが低いカードの中で最も低いものと交換します。交換対象になった感染カードは捨て札になります。

Example — ♥7 を引いた場合
→

最もランクが低い ♥3 が交換対象になり、捨て札へ。エリアには ♥7 が新たに加わります。

引いたカードが最も低い場合 ― エリア内に、引いたカードよりランクが低いカードが存在しない場合、その感染カードはそのまま捨て札になります。

完治したエリアへの感染 ― エリア内の4枚すべてが治療済みの場合、そのエリアは完治状態です。完治状態のカードは裏返しておきます。この状態で同じスートの感染カードを引いた場合、通常の交換はできません。代わりにダイスを1個振ります。

PHASE B

医療班フェーズ｜研究

感染フェーズが終了すると、医療班フェーズになります。まず山札から研究カードを補充し (このタイミングで研究カードは必ず4枚になります)、その後、研究を行うことができます。研究は行わなくてもかまいません。

研究カードから1枚を選び、選んだカードを同じスートのエリアにある任意のカード1枚と交換できます。交換した感染カードは手札の研究カードに回収します。研究によって、感染カードのランクを下げることも、上げることもできます。

Example — 研究カード ♥4 を使用
→

♥9 が ♥4 に置き換わり、エリアの感染力が低下。♥9 は手札に回収されます。

PHASE C

医療班フェーズ｜治療

3個のダイスを振ります。出た目は「移動」または「治療」に自由に割り振れます。3個すべてを移動に使っても、すべて治療に使っても、一部だけでもかまいません。

移動 ― ダイス1個を移動に使用すると、その出目以下のマス数を移動できます。上下左右にのみ移動でき、斜め移動はできません。

出目が 2 の場合の移動可能マス

治療 ― 治療は医療班が現在いるマスに対して行います。治療に使用するダイスの合計値が、そのマスの感染カードのランク以上であれば、そのカードを治療できます。治療されたカードは裏返します。

Example — 現在地の感染カードが ♥7、ダイスは 4・3・2

4 と 3 を治療に使うと合計7となり、♥7 を治療できます。治療できた感染カードは裏返します。

ダイスの割り振り ― ダイスは自由に組み合わせられます。例えば 6・4・3 なら「移動6＋治療3」「移動3＋治療6＋移動4」「治療6＋3」など、プレイヤーが自由に決められます。

ダイスがない場合はここでシミュレーションできます。

PHASE D

医療班フェーズ｜支払い

医療班は、研究維持のために研究データを1枚提出します。研究カードから任意の1枚を選択して捨て札に移動させます (このタイミングで研究カードは必ず3枚になります)。

この後、再び感染フェーズに戻ります。

Failure Condition

アウトブレイク

医療班フェーズ終了後、エリアごとに、未治療のカードのランクを合計します (A = 1、J / Q / K = 10)。合計が残りカード × 4 を超えた場合、そのエリアでアウトブレイクが発生します。

⚠ アウトブレイク発生 = 即敗北

いずれかのエリアでアウトブレイクが発生した時点で、ゲームは失敗となり終了します。

Defeat Condition

敗北条件

いずれかのエリアでアウトブレイクが発生した時点で敗北です (詳細は前項「アウトブレイク」を参照)。

山札がなくなった場合

山札がなくなった場合は、捨て札をシャッフルして新しい山札を作り、ゲームはそのまま継続します。カード枯渇によるゲーム終了はありません。
